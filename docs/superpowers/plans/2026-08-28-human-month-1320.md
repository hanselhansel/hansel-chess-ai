# Human-month climb Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Fine-tune tinyaz-s from Phase 1 on ~1.5M Lichess 2013-01 positions, then 64-visit self-play, and promote public weights only if 64-visit vs Stockfish 18 UCI_Elo 1320 scores a point.

**Architecture:** Extend `tinyaz.data` with hashed game-level split and ply-8 / 4-per-game sampling. New `build_lichess.py` streams the full month. `train_loop.train_candidate` loads Phase 1 weights on MPS. Snapshot keep/discard and self-play both use 64 visits. `promote` to public only on SF score > 0.

**Tech Stack:** Python 3.11, PyTorch MPS, python-chess, zstandard, Stockfish 18 ruler.

Spec: `docs/superpowers/specs/2026-08-28-human-month-1320-design.md`
