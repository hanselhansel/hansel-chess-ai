# Climb-until-1320 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Python while-loop that adds Lichess months, retrains public tinyaz-s, and stops only on a 64-visit point vs 1500 or 32-game MLE > 1320.

**Architecture:** Equal per-month train quotas so later months enter the 1.5M cap. `climb_until.py` downloads the next month, rebuilds, trains from public, rates 1320 then maybe 1500, promotes on strict improvement.

**Tech Stack:** Python 3.11, PyTorch MPS, python-chess, zstandard, Stockfish 18.
