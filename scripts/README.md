# Application Scripts

## Overview

Node entry points and shared helpers for environment flags, Vite integration, browser captures, preview processes, migrations, and sign-out sequencing. CLI paths below assume the repository root. The [package scripts](../package.json) connect these tools to development and build commands.

## Invariants

- App-env parsing retains only string-valued `VITE_` keys from a JSON object. Missing or malformed input becomes `{}`. Process environment entries override file values. `[with-app-env.mjs:parseAppEnv]` `[with-app-env.mjs:readAppEnv]` `[with-app-env.mjs:mergeAppEnv]`
- Only the exact string `"false"` disables auth. An unobserved dev value is `indeterminate`; the standalone check exits 0 for agreement, 1 for divergence, and 2 for indeterminate. It compares the next build's environment, without inspecting built JavaScript. `[check-auth-invariant.mjs:authEnabledFromEnvValue]` `[check-auth-invariant.mjs:compareAuthInvariant]` `[check-auth-invariant.mjs:main]`
- PWA middleware handles GET manifest routes `/__grok/manifest.webmanifest` and `/__grok/manifest.json`. Tutorial interception requires `install=1|true`, `platform=ios`, a document path, and an HTML-compatible Accept header. `[grok-pwa-plugin.mjs:serveGrokPwa]` `[grok-pwa-shared.mjs:isInstallQuery]` `[grok-pwa-shared.mjs:isDocumentPath]` `[grok-pwa-shared.mjs:acceptsHtml]`
- OG title precedence is site title, document title, published-host name, then supplied/default app name. A valid `VITE_PUBLIC_HOSTNAME` precedes the request host. Snapshots remove custom-card/image declarations when no on-disk card exists. `[grok-pwa-shared.mjs:resolveOgTitle]` `[grok-pwa-shared.mjs:resolvePublicHost]` `[grok-pwa-shared.mjs:snapshotOgIdentity]`
- Shared injection replaces managed share metadata. Streaming injection buffers through the first `</head>`, then passes later bytes through. The response wrapper injects only unencoded HTML; `flush()` handles buffered content without a closing head. `[grok-pwa-shared.mjs:injectGrokPwaHead]` `[grok-pwa-shared.mjs:createHeadInjector]` `[grok-pwa-plugin.mjs:wrapHtmlResponses]`
- Capture targets require HTTP(S) loopback URLs unless `BROWSER_ALLOW_EXTERNAL_HOST=1` relaxes the hostname restriction. Output checks use resolved path prefixes: smoke outputs must be below `/workspace`; thumbnails permit `/tmp` or `/workspace`. These output checks do not resolve symlinks. `[browser-guard.mjs:checkedUrl]` `[browser-guard.mjs:checkedOutputPath]` `[browser-smoke.mjs:outPng]` `[preview-thumbnail.mjs:outPng]`
- Smoke baselines are realpathed below `/workspace`, must differ from this run's verdict path, and are limited to 1 MiB. Unreadable or invalid verdicts report baseline divergence. `[browser-smoke.mjs:baselinePath]` `[browser-smoke.mjs:MAX_BASELINE_BYTES]` `[browser-smoke.mjs:compareAgainstBaseline]` `[browser-smoke-verdict.mjs:baselineComparison]`
- Smoke exits 1 for missing viewport data or HTTP status 0/400+, otherwise 2 for console/page errors, otherwise 0. Baseline divergence, overflow, brand warnings, and auth warnings do not independently change this code. Thumbnail capture does not fail solely on an HTTP error status. `[browser-smoke-verdict.mjs:exitCodeFor]` `[preview-thumbnail.mjs:status]`
- Parent brand warnings are suppressed while `.grok/og-pending` is younger than 10 minutes. The standalone CLI ignores suppression and requires a custom card unless `--placeholder-ok`. Game checks require `type: "x:game"` and, once a card exists, `x-banner.jpg`. Existing cards/banners over 600 KiB warn. `[brand-check.mjs:computeBrandWarnings]` `[brand-check.mjs:OG_PENDING_MAX_AGE_MS]` `[brand-check.mjs:brandWarningsOnDisk]` `[brand-check.mjs:MAX_CARD_BYTES]`
- Preview control requires Linux `/proc` and owns port 8081. Actual port owners qualify regardless of command; a PID-file candidate requires a current preview command match. Stop fails if survivors or unattributed listeners remain. Any HTTP response counts as restart readiness. `[preview.mjs:portOwners]` `[preview.mjs:previewOwners]` `[preview.mjs:stopOutcome]` `[preview.mjs:waitForReady]`
- Migration selection is nonrecursive, filters `.sql`, sorts by basename, and skips recorded basenames. Nested auth migrations are not selected. Each SQL file and its `_migrations` insertion share one transaction; failures attempt rollback. `[migration-plan.mjs:pendingMigrations]` `[migrate.mjs:main]`
- Sign-out waits default to 1500 ms in live preview and 10000 ms otherwise. Preview clears then redirects after a best-effort request, skipping the request without a bearer. Deployed sign-out requires request success; failures/timeouts throw before clear/redirect. Request callbacks must reject failed responses. Pre-sign-in cleanup is best effort and clears without redirecting. Timed-out requests are not cancelled. `[sign-out-plan.mjs:signOutTimeoutMs]` `[sign-out-plan.mjs:runSignOut]` `[sign-out-plan.mjs:runPreSignInSignOut]` `[sign-out-plan.mjs:settleWithin]`
- The atomic-write CLI resolves paths against the repository root and rejects identical staged/target paths or staging inside `public/`. `handOver()` uses rename and rejects cross-filesystem `EXDEV`, without copying. Direct callers must apply staging validation separately. `[write-atomic.mjs:stagingError]` `[write-atomic.mjs:handOver]` `[write-atomic.mjs:ROOT]`

## Side Effects

- The environment wrapper reads `.grok/app-env.json`, spawns the requested child with inherited stdio, forwards `SIGINT`/`SIGTERM`/`SIGHUP`, and propagates child exit status. Missing commands exit 2; spawn errors exit 127. `[with-app-env.mjs:readAppEnv]` `[with-app-env.mjs:main]` `[with-app-env.mjs:exitStatusFromChild]`
- Vite plugins register middleware and write response headers/bodies. PWA wrapping replaces response `write`/`end`; rendering reads the install template and OG identity files/assets. The auth probe fetches `/__app-env` and reads local build flags. `[app-env-plugin.mjs:appEnvPlugin]` `[grok-pwa-plugin.mjs:renderInstallPage]` `[grok-pwa-plugin.mjs:wrapHtmlResponses]` `[check-auth-invariant.mjs:probeDevAuthEnabled]` `[check-auth-invariant.mjs:buildAuthEnabled]`
- Shared identity helpers read site/card/banner files and environment values `VITE_PUBLIC_HOSTNAME`, `VITE_PROJECT_ID`, `VITE_OG_SERVICE_URL`, `X_CREATOR`, and `X_CREATOR_ID`. Generated HTML references the external Grok extensions script and OG/custom image URLs, without fetching them in these helpers. The install template updates document device/iOS classes. `[grok-pwa-shared.mjs:normalizeHeadContext]` `[grok-pwa-shared.mjs:grokExtensionsHeadTags]` `[grok-pwa-shared.mjs:grokOgHeadTags]` `[install-page.html:root.className]`
- Smoke and thumbnail modules launch Playwright Chromium at module evaluation with `--no-sandbox` and `--disable-dev-shm-usage`, navigate, and write PNGs. Smoke creates output directories, reads assets/baselines, and writes desktop/mobile screenshots plus verdict JSON. Both print results and close the browser in `finally` after launch. Capture timeouts default to 45000 ms via `BROWSER_SMOKE_TIMEOUT_MS` or `PREVIEW_THUMBNAIL_TIMEOUT_MS`. `[browser-smoke.mjs:browser]` `[browser-smoke.mjs:VIEWPORTS]` `[browser-smoke.mjs:timeoutMs]` `[preview-thumbnail.mjs:browser]` `[preview-thumbnail.mjs:timeoutMs]`
- Brand checking reads/stats site metadata, share assets, and the pending marker. Its CLI prints JSON and sets a failure exit code for `BRAND WARNING` messages. `[brand-check.mjs:brandWarningsOnDisk]` `[brand-check.mjs:ogPendingActive]` `[brand-check.mjs:isBrandWarning]`
- Preview stop reads `/proc` and `.grok/preview.pid`, sends `SIGTERM`, then `SIGKILL` after a 3000 ms grace period, and removes the PID file on success. Signals target a process group only when the PID is its leader. Restart spawns detached `npm run preview`, appends `.grok/preview.log`, writes the PID file, and polls HTTP. `PREVIEW_READY_TIMEOUT_MS` defaults to 60000; failed readiness triggers cleanup. `[preview.mjs:stop]` `[preview.mjs:terminatePids]` `[preview.mjs:killPid]` `[preview.mjs:restart]` `[preview.mjs:READY_TIMEOUT_MS]`
- With `DATABASE_URL` and eligible root SQL files, migration connects through external `pg`, creates `_migrations(name, applied_at)`, executes pending SQL, and records applied names. Missing configuration or eligible files skips the connection. `[migrate.mjs:databaseUrl]` `[migrate.mjs:main]`
- `handOver()` checks staging existence, creates target parent directories, and renames the staged file onto the target. A failed rename can leave newly created directories. `[write-atomic.mjs:handOver]`
- Sign-out helpers schedule timers and invoke supplied callbacks; network, storage, and navigation implementations belong to those callbacks. `[sign-out-plan.mjs:settleWithin]` `[sign-out-plan.mjs:runSignOut]`
- None for the migration planner and smoke-verdict helpers beyond computation. `[migration-plan.mjs:pendingMigrations]` `[browser-smoke-verdict.mjs:compareToBaseline]`

## Verification

Run from the repository root:

```sh
npm run test:scripts
npm run test:core
npm test
npm run typecheck
```

`npm test` is `npm run test:scripts && npm run test:core`: `node --test 'scripts/**/*.test.mjs'` first, then `node --experimental-strip-types --test 'src/**/*.test.ts'` so later core tests are discovered automatically. A script-test failure prevents that second stage. `typecheck` runs `tsc --noEmit`. `[../package.json:scripts.test]` `[../package.json:scripts.test:scripts]` `[../package.json:scripts.test:core]` `[../package.json:scripts.typecheck]`

Script-test fixtures are portable: app-env/auth tests build temporary roots containing `.grok/app-env.json` and execute a byte-identical copy of `with-app-env.mjs` from the fixture's own `scripts/` directory, so nothing depends on this checkout's absent `.grok` files or ambient `VITE_*`/`X_*` values. The PWA suite is split into `grok-pwa-head.test.mjs` (head/meta/card cases) and `grok-pwa-plugin.test.mjs` (install, streaming, manifest, and deployment-integration cases); the real Vite config `serverDir` wiring, Nitro middleware/assets, virtual-identity plugin source, install template, icon, and install stylesheet assertions remain in the latter and still read this checkout's actual files. Both files isolate `cwd`, `site`, and the `VITE_PUBLIC_HOSTNAME`/`VITE_OG_SERVICE_URL`/`VITE_PROJECT_ID`/`X_CREATOR`/`X_CREATOR_ID` worker flags.

`npm run test:template-authoring` is a separate upstream authoring gate, not part of `npm test`: the four document checks pin `AGENTS.md` and the og skill's `SKILL.md`/`references/` prose to this checkout's real parsers and marker constants inside an explicit `GROK_TEMPLATE_ROOT` checkout. Missing input fails nonzero; see [template-authoring/README.md](./template-authoring/README.md). `[../package.json:scripts.test:template-authoring]`

Against an already running dev server, `npm run check:auth -- --dev-url http://127.0.0.1:8080` checks environment agreement. It performs an HTTP probe. `[../package.json:scripts.check:auth]` `[check-auth-invariant.mjs:main]`
